# plugins：给具体产品做的插件

现在是空的。

这里放的是装进某个产品里的东西：一个产品自己的插件格式、应用商店的上架包、带界面的扩展。只用填一个接入地址就能接上的产品不需要插件，它们的步骤在 [`connectors/`](../connectors)。

什么时候往这里加：某个产品只填接入地址接不上，或者接上了但做不了该做的事（比如存不回笔记），而它的插件机制能补上。加之前先在 spec 的 [接入一个助手](https://github.com/KeepEssenceApp/spec/blob/main/product/connect.md) 里写明查实过的情况。

插件和别的助手用同一份契约，没有额外的接口（规则 D1）。
